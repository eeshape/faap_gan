# L2 대체 Loss 조사·정리 (KD 제외 / 분포정합 관점)

**이도형 / 2026.06.17 / CVLab**

> 교수님 피드백: **RKD는 지식증류(Knowledge Distillation, KD) 기법 → 우리 task와 맞지 않음.**
> → loss를 "KD(teacher→student 지식 전이)"가 아니라 **"clean-male 분포에 perturb-male을 맞추는 정합(alignment)·일관성(consistency)"** 관점으로 재정의하고, 후보를 폭넓게 조사.
>
> **이번 업데이트 목적**: 교수님 지시 — 후보 loss 중 **3개를 선별해 실험**하기 위한 **장단점 매우 구체화 + 선별 근거** 정리.

---

## 0. 우리 task의 실제 제약 (모든 장단점 판단의 기준)

L2 anchor가 하던 역할 = **contrastive가 female을 male로 끌 때, perturb-male feature가 clean-male feature에서 멀어지며(드리프트) male 검출 성능이 무너지는 것을 막는 정칙화**.
즉 **정렬 대상 = clean-male feature(고정 타겟) ↔ perturb-male feature(gradient 흐름)**, 두 분포의 거리를 줄이는 문제.

이 task에는 **loss 선택을 좌우하는 4개의 강한 제약**이 있다 (이하 C1~C4로 인용):

| ID | 제약 | 수치/근거 | 함의 |
|---|---|---|---|
| **C1** | **극소표본 male** | `batch_size=5` (코드 기본값, baseline과 동일하게 교란변수 통제) → 배치당 male **약 2~3개** | **공분산(2차) 추정 불가능**: 표본 공분산 rank ≤ N−1 ≤ 4 |
| **C2** | **고차원 feature** | GAP-pooled DETR decoder **d=256** (또는 proj **d=128**) | d ≫ N → 공분산은 256×256인데 rank≤4 → 거의 noise |
| **C3** | **BF16 학습** | mixed precision | `sqrtm`(행렬제곱근)·역행렬 **수치 불안정** → Bures/KL-Gauss 위험 |
| **C4** | **fairness shift 허용 필요** | 목표는 male 보존이지 male **절대좌표 동결**이 아님 | 절대위치 과고정(L2)은 공정성 이동 여지를 막음 → no_l2 ablation의 이유 |

추가 근거:
- **C5 (프로젝트 이력)**: 본 repo는 이미 **MMD**(`구실험파일/train_faap_mmd_1st·2nd.py`, multi-scale RBF σ∈{1,2,4,8,16})와 **1D Wasserstein**(score 단방향 정렬)을 사용 → 분포정합 계열은 task 친화적이고 "근거"가 강하며 **코드 재활용** 가능.

**선별 기준 (교수님 지적 반영)**
1. **KD 계열이 아닌가** — teacher→student 지식전이형 제외.
2. **male 그룹의 위치/분포를 직접 잡는가** — 드리프트·붕괴 차단.
3. **fairness shift를 과하게 막지 않는가** (C4).
4. **C1·C2·C3에서 안정적인가** — 소표본·고차원·BF16에서 동작하는가.

## 1. 후보 Loss 전수 정리 (장단점 구체화)

표기: male feature $f_i\in\mathbb{R}^d$ ($d$=256 또는 128), clean=c(타겟·detach) / perturb=p(gradient), $N$=배치 내 male 수(≈2~3, C1).

### A. 점별 feature 정합 (Point-wise) — non-KD, baseline 계열

| Loss | 수식 | 무엇을 정합 |
|---|---|---|
| **L2 / MSE** | $\frac1N\sum\lVert f_i^p-f_i^c\rVert^2$ | 절대 위치 |
| **L1 / MAE** | $\frac1N\sum\lVert f_i^p-f_i^c\rVert_1$ | 절대 위치 |
| **Smooth-L1 / Huber** | 0근처 2차, 멀면 1차 | 절대 위치 |
| **Cosine** | $\frac1N\sum(1-\cos(f_i^p,f_i^c))$ | 방향 |

**L2 / MSE (E0 baseline)**
- 장점:
  - **소표본 완전 무관(C1)**: 같은 male 이미지의 clean vs perturb를 1:1 매칭하므로 N=1에서도 정의. rank 문제 없음.
  - **BF16 안전(C3)**: 제곱·합뿐, sqrtm/역행렬 없음.
  - 구현 1줄, gradient 안정, 명확한 대조 기준선.
- 단점:
  - **절대좌표 과고정(C4 정면 위배)**: clean-male의 정확한 좌표에 perturb-male을 못박음 → 공정성을 위한 male 분포의 미세 이동조차 차단. **이것이 no_l2 ablation을 수행한 핵심 동기**.
  - 제곱이라 **이상치 1개가 loss 지배** → 소표본(C1)에서 특정 male 샘플에 과적합.
  - 256차원 **등방성 가정** — feature별 스케일 차이 무시.
  - "분포"가 아닌 "샘플"을 맞춤 → 방향 자유 0.

**L1 / MAE**
- 장점: 이상치 강건(선형 패널티) → C1의 소표본 이상치 문제 완화. BF16 안전.
- 단점: **0에서 미분 불연속**(서브그라디언트, 수렴 느림). 절대좌표 고정 문제는 L2와 동일(C4). **신규성 낮음**(L2 변형) → 별도 실험 가설로서 약함.

**Smooth-L1 / Huber**
- 장점: L2 안정성 + L1 강건성 절충. BF16 안전.
- 단점: δ 튜닝. **여전히 절대좌표 고정 계열**(C4 미해결). 신규성 낮음.

**Cosine distance**
- 장점: 크기 자유(방향만 정합) → 스케일은 풀어줌.
- 단점: **치명적 신규성 부재** — male feature가 이미 정규화되거나 GAP 후 비슷한 norm이면 **L2와 거의 동일**. 방향만 맞추면 norm 드리프트/collapse 방치. 별도 실험 가치 낮음.

### B. 통계·분포 정렬 (Statistical) — non-KD ★핵심군

| Loss | 수식 | 무엇을 정합 |
|---|---|---|
| **Centroid / Prototype**(1차) | $\lVert\mu^p-\mu^c\rVert^2$ | 군집 평균(위치) |
| **CORAL**(2차) | $\frac{1}{4d^2}\lVert C^p-C^c\rVert_F^2$ | 공분산(퍼짐) |
| **MMD**(RBF, 전차수) | $\lVert\tfrac1n\sum\phi(f_i^p)-\tfrac1m\sum\phi(f_j^c)\rVert_\mathcal{H}^2$ | 분포 전체(모든 모멘트) |
| **Bures / 2-Wasserstein(Gauss)**(2차) | $\mathrm{Tr}(C^p{+}C^c{-}2(C^{c1/2}C^pC^{c1/2})^{1/2})$ | 가우시안 분포 |
| **KL / JS(Gauss)** | $\mathrm{KL}(\mathcal N^p\Vert\mathcal N^c)$ | 분포(가정형) |

**Centroid / Prototype Alignment (1차 모멘트)**  ★선별
- 장점:
  - **핵심 실패모드 정조준**: contrastive가 망가뜨리는 건 "male 평균이 female 쪽으로 끌려가는 드리프트". 1차 모멘트를 직접 고정 → **드리프트를 가장 선명하게 차단**.
  - **소표본 최강(C1)**: 평균은 N=2~3에서도 안정적으로 정의(공분산과 달리 rank 무관). 본 task 제약에 가장 잘 맞음.
  - **매우 쌈** O(Nd), **BF16 완전 안전**(mean·내적뿐).
  - **개별 샘플 위치는 자유** → 분포 "모양"은 안 건드리고 평균만 잡음. L2(샘플 동결)보다 fairness 여지 큼.
  - EMA centroid로 배치 노이즈 완화 가능(C1 대응): batch=5라 **EMA 권장**(momentum≈0.9).
- 단점:
  - **1차만** → 분산/모양 미보존: 평균은 같은데 male feature가 **퍼지거나 한 점으로 collapse**해도 loss=0 (감지 불가).
  - 단독으로는 분포 정합이 불완전 → **collapse 감지용 보조항** 또는 MMD 결합(E4) 권장.

**CORAL (2차 공분산)**  ✕ 본 task 부적합
- 장점: closed-form, Frobenius라 미분 안정, 공분산(퍼짐) 정합 개념은 적절.
- 단점:
  - **치명적(C1+C2)**: d=256, N≤5 → 표본 공분산 **rank ≤ 4**. 256×256 행렬을 rank 4로 추정 → 추정량이 사실상 noise, 정렬 방향이 무의미. CORAL은 본래 **N ≫ d**(수백~수천 샘플) 전제.
  - **평균(1차) 미보존** → 드리프트(핵심 실패모드)를 직접 못 막음.
  - 256² 행렬 연산 대비 정보량 빈약 → 비용 대비 효과 최악.
  - → **대조군으로만 가치**(소표본에서 2차 단독이 왜 실패하는지 보이는 용도).

**MMD (RBF, multi-scale)**  ★선별 (주력)
- 장점:
  - **전차수 모멘트 동시 정합**: 커널이 평균(1차)+분산(2차)+고차를 한 번에 → centroid·CORAL의 **상위 호환**.
  - **소표본 강건(C1)**: 명시적 공분산 추정 없이 **커널 그람행렬**로 분포 거리 계산 → **rank 문제 없음**. N=2~3에서도 정의되며(편향만 존재) 동작. CORAL/Bures를 대체할 수 있는 이유.
  - **비모수**: 분포 가정 불필요.
  - **BF16 안전(C3)**: exp·내적만, sqrtm/역행렬 없음.
  - **프로젝트 이력(C5)**: multi-scale σ∈{1,2,4,8,16} 구현 존재 → X(perturb-male)·Y(clean-male)만 바꾸면 즉시 사용, 재현·근거 강함.
- 단점:
  - **커널 bandwidth σ 민감** → multi-scale로 완화하나 feature 스케일 따라 튜닝 필요.
  - 소표본(N=2~3)에서 MMD **추정 분산 큼** → gradient noisy(단 centroid보다 정보 풍부, 절충 가능).
  - O(N²) 그람행렬(N 작아 부담은 없음).
  - 평균은 빠르게, 고차는 약하게 정합 → "드리프트 직접 차단"의 선명함은 centroid보다 다소 흐릴 수 있음(→ centroid와 상보).

**Bures / 2-Wasserstein (Gaussian)**  ✕ 부적합
- 장점: 평균+공분산을 기하적으로 정확히 정합(가우시안 최적수송).
- 단점:
  - **치명적(C3)**: `sqrtm`(행렬제곱근) 필수 → **BF16 수치 불안정**, 역전파 비용 큼.
  - **C1+C2**: 공분산 rank-deficient → $C^{c1/2}C^pC^{c1/2}$ 자체가 ill-conditioned.
  - 가우시안 가정 + 구현 복잡 → 후순위.

**KL / JS (Gaussian)**  ✕ 부적합
- 장점: 정보이론적으로 명확.
- 단점: 가우시안 가정 + **공분산 역행렬** 필요 → C1·C2(rank 부족)·C3(BF16) **모두 위배**. 역행렬 폭발. 제외.

### C. 최적수송 (Optimal Transport) — non-KD

| Loss | 수식 | 무엇을 정합 |
|---|---|---|
| **Wasserstein-1 (1D/sliced)** | 정렬 후 $\frac1k\sum\lvert\mathrm{sort}(f^p)-\mathrm{sort}(f^c)\rvert$ | 분포(수송거리) |
| **Sinkhorn (entropic OT)** | 엔트로피 정칙 OT(미분가능) | 분포(수송 plan) |

**Wasserstein / Sinkhorn (feature)**  ★선별 (제3의 메커니즘)
- 장점:
  - **프로젝트 이력(C5)**: score에 **단방향 1D Wasserstein** 이미 사용(`_wasserstein_1d`, sort 기반) → **feature 분포 정렬로 확장이 자연스럽고 코드 재활용**.
  - **MMD와 다른 기하**(커널 vs 수송) → "전차수 정합"을 **독립적 메커니즘으로 교차검증**. 두 방법이 대등하면 결과 신뢰도↑, 다르면 상보.
  - **1D sliced는 sort만** → BF16 안전(C3), 소표본서도 정의.
  - 분위수 매칭이라 **평균·분산·모양 암묵 정합**.
- 단점:
  - **고차원(256-d)은 random projection으로 sliced** 필요 → projection 개수/방향 튜닝, 분산 큼.
  - 1D sliced는 **차원간 상관(joint) 무시**(marginal만).
  - Sinkhorn은 ε·반복수 튜닝 + 비용↑이며, **N=2~3에선 OT plan이 3×3 수준이라 OT의 이점이 거의 사라짐**(수송행렬이 자명에 가까움) → 본 task에선 **sliced-Wasserstein 우선**, Sinkhorn은 후순위.

### D. 지식증류 계열 (KD) — ✕ 부적합 (교수님 지적), 참고용

| Loss | 계열 | 왜 KD이고 왜 부적합인가 |
|---|---|---|
| **RKD** (Relational KD) | 관계 전이 | clean의 관계 구조를 "지식"으로 전이 → 전형적 KD. 절대위치도 안 잡음 |
| **KL-logit (Vanilla KD)** | 출력 분포 전이 | teacher logit→student. 우리는 feature 정합이지 logit 모방 아님 |
| **FitNets (Hint)** | 중간층 전이 | teacher 중간 feature를 student가 회귀 → KD |
| **Attention Transfer** | attention map 전이 | KD |
| **CRD** (Contrastive Rep. Distillation) | 대조형 KD | KD + 기존 contrastive와 충돌 |

### E. 기타 구조/정칙화 (경계)

| Loss | 메모 |
|---|---|
| **Jacobian / Gradient matching** | detector 민감도 보존. 단 **"Jacobian matching"은 KD 변형**으로 알려짐 + **이중 역전파**로 무겁고 BF16서 불안정 → 후순위 |
| **Orthogonality / Subspace(PCA) alignment** | male 부분공간(주성분) 정렬. 분포정합의 일종이나 **C1+C2에서 PCA 부분공간 추정 자체가 rank 부족** + 구현 복잡 → 후순위 |

## 2. KD 여부 + task 적합성 한눈 정리

```
[non-KD · 분포정합/일관성]  ← 우리 task에 적합
  점별:   L2 · L1 · Smooth-L1 · Cosine      (절대좌표 고정 계열, C4 약점)
  통계:   Centroid ★ · MMD ★ · CORAL✕ · Bures✕ · KL✕
  OT:     Wasserstein ★ · Sinkhorn(후순위)

[KD · 지식전이]            ← 교수님 지적: 부적합
  RKD · KL-logit · FitNets · Attention Transfer · CRD

[경계 · 후순위]
  Jacobian matching(KD 변형+무거움) · Subspace alignment(소표본 rank 부족)

✕ 소표본/BF16 탈락 사유 요약
  CORAL · Bures · KL-Gauss : 공분산 rank ≤ N−1 ≤ 4 ≪ d=256 (C1·C2),
                             Bures/KL은 sqrtm·역행렬로 BF16 불안정(C3)
```

## 3. 최종 선별 — 실험할 3개 + 근거 (교수님 보고용)

L2(E0)는 **대조 기준선**으로 두고, 그 위에서 비교할 **앵커 loss 3종**을 다음과 같이 선별한다.

| 선택 | Loss | 정합 차수 | 메커니즘 | 핵심 선별 근거 |
|---|---|---|---|---|
| **① Centroid Alignment** | 평균만(1차) | 좌표 고정 | **핵심 실패모드(male 평균 드리프트)를 직접·최소비용으로 차단**. C1(소표본)·C3(BF16)에서 가장 안전. "최소 정합" 하한선. |
| **② MMD (RBF multi-scale)** | 전차수 | 커널 | **centroid·CORAL의 상위 호환**(평균+분산+고차 동시), 소표본서 공분산 추정 없이 동작(C1) → CORAL/Bures를 대체. **프로젝트 이력(C5)**으로 근거·재현성 강함. **주력 후보**. |
| **③ Sliced-Wasserstein (feature)** | 전차수 | 최적수송 | MMD와 **독립적 기하**로 전차수 정합을 **교차검증**. 본 repo가 score에 이미 Wasserstein 사용(C5) → feature 확장이 자연스럽고 코드 재활용. |

**왜 정확히 이 3개인가 (선별 논리)**
1. **세 가지 서로 다른 정합 철학을 1·전차수로 사다리(ladder) 구성** — "평균만(①) → 전차수·커널(②) → 전차수·수송(③)". 단조적 ablation이 되어, *어느 차수의 정보가 male 보존에 필요한지*를 깔끔히 분리할 수 있음.
2. **4개 선별 기준을 모두 통과**: 전부 non-KD(기준1), male 분포를 직접 정합(기준2), 절대좌표를 동결하지 않음(기준3, L2 대비), C1·C2·C3에서 안정(기준4).
3. **탈락 사유가 구체적**: CORAL/Bures/KL은 **공분산 rank ≤ 4 ≪ 256**(C1·C2)와 sqrtm·역행렬 BF16 불안정(C3)으로 정량적으로 부적합. L1/Smooth-L1/Cosine은 **L2의 사소한 변형**이라 독립 가설 가치가 없음.
4. **근거의 강도**: ②·③은 **프로젝트 이력(C5)**이 있어 "왜 이 loss인가"에 대한 답이 명확하고 재현 위험이 낮음. ①은 핵심 실패모드를 직접 겨냥하는 **가장 싼 통제군**.
5. **상보 관계**: ②(커널)와 ③(수송)이 **같은 결론이면 신뢰도↑**, 다르면 어느 기하가 이 feature 공간에 맞는지 추가 정보를 얻음. ①은 둘의 하한 대조.

### 제안 실험 매트릭스 (교란변수 통제)
**고정**: contrastive(λ_con=5.0, τ=0.05), batch=5, epsilon 스케줄, β 스케줄, 동일 seed/epoch. **변경**: anchor loss만 교체.

| # | 앵커 | 검증 가설 |
|---|---|---|
| **E0** | L2 (baseline) | 절대좌표 고정 기준선. no_l2 대비 male 얼마나 보존? |
| **E1** | **Centroid** | 평균 드리프트 차단만으로 male이 보존되는가 (1차로 충분한가) |
| **E2** | **MMD** | 전차수 정합이 1차(centroid)·2차보다 나은가 (주력) |
| **E3** | **Sliced-Wasserstein** | OT 정합이 MMD와 대등/상보인가 (기하 교차검증) |
| (E4) | Centroid+MMD | 위치(1차)+분포(전차수) 결합이 단독을 능가하는가 (여력 시) |

### 함께 볼 진단 지표 (loss별 성패 판정용)
- **male AP 보존**(↑가 목표) vs **AP Gap**(↓가 목표) — 1차 성과지표.
- **male centroid drift** $\lVert\mu^p-\mu^c\rVert$ — 드리프트 직접 측정.
- **male feature 분산/유효차원** — collapse 감지(특히 ① centroid는 분산을 안 보므로 필수).
- contrastive loss·det loss 곡선 — 학습 안정성(이전 fix1의 collapse·음수 loss 재발 여부).

## 4. 한 줄 요약
KD(지식전이) 계열은 제외하고, 우리 task를 **clean↔perturb male "분포 정합" 문제**로 재정의 → **소표본(batch=5, N_male≈2~3)·고차원(d=256)·BF16** 제약 때문에 공분산 기반(CORAL·Bures·KL)은 rank 붕괴로 탈락.
**실험 대상 3종 = ① Centroid(1차·드리프트 직접 차단) · ② MMD(전차수·커널·주력) · ③ Sliced-Wasserstein(전차수·수송·교차검증)** — 정합 차수의 사다리를 이루고, ②·③은 프로젝트 이력으로 근거가 강하며, 모두 C1~C4를 통과한다.

## 5. 교수님 보고용 — 선정 3종 상세 (Centroid · CORAL · Jacobian Frobenius Anchor)

> 본 절은 교수님 보고를 위해 **Centroid · CORAL · Jacobian Frobenius Anchor** 3종만 상세화한다.
> (1~3절의 폭넓은 조사에서는 CORAL=✕, Jacobian=후순위로 분류했으나, 교수님 지시에 따라 이 3종을 보고 대상으로 삼는다.
> 대신 아래 **장단점에서 그 한계(CORAL의 소표본 rank, Jacobian의 이중 역전파·BF16)를 정량적으로 명시**하여, "왜 그럼에도 보고/실험 가치가 있는가"를 정직하게 서술한다.)

### 핵심 narrative — "anchor가 *무엇을* 보존하는가"의 사다리(ladder)

male anchor의 목적은 동일하다: **contrastive가 female을 male로 끌 때 perturb-male이 clean-male에서 드리프트하는 것을 막는 것.** 단, "무엇을 같게 만들어 막을지"의 **보존 대상이 차수(order)별로 다르다**:

| | 보존 대상 | 차수 | 직관 |
|---|---|---|---|
| **① Centroid** | male 군집의 **위치(평균)** | 1차 모멘트 | "male이 *어디에* 있는가"를 고정 |
| **② CORAL** | male 군집의 **모양·퍼짐(공분산)** | 2차 모멘트 | "male이 *어떻게 퍼져* 있는가"를 고정 |
| **③ Jacobian Frobenius** | male 주변 검출기의 **함수적 민감도(국소 기하)** | 미분(구조) | "male에 대해 검출기가 *어떻게 반응*하는가"를 고정 |

→ 값(위치) → 분포(모양) → 함수(반응)로 **보존 수준이 점점 깊어지는 사다리**. 세 실험이 "male 보존에 *어느 수준*의 제약이 실제로 필요한가"를 단계적으로 분리해 답한다.

**경험적 동기 (왜 anchor가 필요한가, 우리 데이터):** epoch 8 t-SNE에서 **남성 feature 이동량 disp_male = 0.169**로, **두 성별 클러스터 간격(center_dist=0.053)의 3.17배**, 여성 이동량의 1.11배만큼 표류했다. male은 "여성이 따라갈 고정 표적"이어야 하는데 표적 자체가 격차의 3배로 흔들리고 있음 → anchor 도입의 직접 근거.

### 5.1 Centroid (Prototype) Alignment — 1차 모멘트 정합

**Loss 정의**

배치 내 male feature를 clean(타겟, detach)과 perturb(gradient)로 나누고 각 평균(centroid)을 맞춘다.

$$\mu^c=\frac1N\sum_{i=1}^{N} f_i^{c},\qquad \mu^p=\frac1N\sum_{i=1}^{N} f_i^{p},\qquad \mathcal{L}_{\text{cent}}=\bigl\lVert \mu^p-\mu^c\bigr\rVert_2^2$$

- $f_i\in\mathbb{R}^d$ (d=256 decoder GAP feature 또는 d=128 projection), $N$=배치 내 male 수(≈2~3, C1).
- 안정화: batch=5로 $\mu$ 노이즈가 크므로 **EMA centroid**(momentum≈0.9) 권장 — clean-male 평균을 학습 전체에 걸쳐 누적해 소표본 분산을 흡수.

**내 Task에서의 역할**

contrastive의 핵심 부작용은 *"male 평균이 female 쪽으로 끌려가는 드리프트"*다 (5절 도입의 disp_male 근거). Centroid loss는 **이 1차 드리프트를 가장 직접적으로, 최소 비용으로 차단**한다. male의 절대 좌표(개별 샘플)는 풀어주되 **군집의 무게중심만** clean에 고정 → "male이 통째로 이동하는 것"만 막는다.

**선정 이유 / 적용 근거**

- **핵심 실패모드 정조준**: 우리가 막고 싶은 1순위가 평균 드리프트이고, 그것을 정확히 1:1로 겨냥하는 가장 단순한 항. "최소 정합(minimal anchor)"의 하한선 역할.
- **제약 적합성 최강**: 평균은 $N=2{\sim}3$에서도 안정 정의(C1 통과, 공분산처럼 rank 무관), mean·내적만이라 **BF16 완전 안전**(C3), $O(Nd)$로 매우 쌈.
- **fairness shift 여지 보존(C4)**: 개별 male 샘플 위치를 동결하는 L2와 달리 평균만 잡으므로 분포 내부의 미세 이동(공정성 보정)은 허용.

**다른 loss 대비 장단점**

- vs **L2(E0)**: L2는 *샘플별 절대좌표*를 동결(C4 위배, 이상치 1개가 loss 지배) → centroid는 평균만 잡아 **자유도와 강건성 모두 우위**. "L2가 과한가"를 검증하는 직접 대조군.
- vs **CORAL/MMD**: centroid는 **분산·모양을 전혀 안 봄** → 평균은 같은데 male이 **퍼지거나 한 점으로 collapse**해도 loss=0(감지 불가). 이것이 단독 사용의 명확한 약점.
- **요약**: 가장 싸고 안전하며 핵심을 직접 겨냥하지만, "1차만"이라 분포 붕괴를 못 본다 → **반드시 male 분산/유효차원을 진단지표로 병행**해야 함.

### 5.2 CORAL (CORrelation ALignment) — 2차 모멘트(공분산) 정합

**Loss 정의** (Deep CORAL; Sun & Saenko, 2016)

male feature의 공분산 행렬을 clean과 perturb 간에 맞춘다.

$$C^{\cdot}=\frac{1}{N-1}\sum_{i=1}^{N}\bigl(f_i^{\cdot}-\mu^{\cdot}\bigr)\bigl(f_i^{\cdot}-\mu^{\cdot}\bigr)^{\!\top}\in\mathbb{R}^{d\times d},\qquad \mathcal{L}_{\text{CORAL}}=\frac{1}{4d^2}\bigl\lVert C^p-C^c\bigr\rVert_F^2$$

- $\lVert\cdot\rVert_F$=Frobenius norm, $1/4d^2$=차원 정규화(원논문 관례).
- 보통 평균(1차)은 별도로 안 잡으므로 실무에선 **centroid와 결합**해 1차+2차를 함께 정합.

**내 Task에서의 역할**

centroid가 못 보는 **"male 군집의 퍼짐·상관 구조"를 보존**한다. contrastive 압력으로 male이 평균은 유지하면서 **분산이 줄어들어 collapse**하거나 **특정 방향으로 늘어나면** male feature의 표현력이 망가지는데, CORAL은 이 2차 변형을 직접 잡아 **검출에 필요한 feature 다양성**을 지킨다.

**선정 이유 / 적용 근거**

- **2차 정합의 명시적 대표**: 사다리의 "분포 모양" 단계를 채우는 closed-form·미분안정(Frobenius) loss. "1차(centroid)로 충분한가, 2차가 필요한가"를 가르는 **결정적 ablation 지점**.
- **개념적 적합성**: 공분산 정합은 도메인 적응에서 분포 정렬의 표준 → "clean↔perturb male 분포 정합"이라는 우리 재정의에 직접 부합.
- **(정직한 단서) 보고 가치**: 아래 단점대로 소표본에서 이론적 약점이 크지만, 바로 그 때문에 **"소표본·고차원에서 2차 단독 정합이 왜 실패/한계인가"를 실험으로 보여주는 대조군**으로서의 보고 가치가 있다.

**다른 loss 대비 장단점**

- 장점: closed-form, Frobenius라 sqrtm/역행렬 없이 **미분 안정**(Bures/KL-Gauss보다 안전), 공분산이라는 *해석 가능한* 2차량을 직접 정합.
- 단점(치명적):
  - **소표본 rank 붕괴(C1+C2)**: $d=256$, $N\le5$ → 표본 공분산 $C$의 **rank ≤ $N-1$ ≤ 4 ≪ 256**. 256×256 행렬을 rank 4로 추정 → 추정량이 사실상 noise, 정렬 방향 무의미. CORAL은 본래 $N\gg d$(수백~수천) 전제. → **EMA 공분산 누적**으로 완화 시도는 가능하나 근본 해결은 아님.
  - **평균(1차) 미보존**: 드리프트(핵심 실패모드)를 직접 못 막음 → centroid와 **반드시 결합** 필요.
  - **비용 대비 정보 빈약**: $256^2$ 행렬 연산을 하면서 얻는 신뢰 정보는 rank 4뿐.
- vs **MMD**: MMD는 커널 그람행렬로 **공분산을 명시 추정하지 않고** 전차수를 정합 → 소표본서 rank 문제 없이 2차 이상의 정보까지 얻음. 즉 **CORAL의 상위 호환**이며, 소표본 제약에서 MMD가 CORAL보다 유리한 이유가 명확.
- **요약**: "2차 정합"의 개념적 대표지만, **우리 소표본·고차원 제약에서는 가장 약한 후보**. 보고에서는 *2차 단독 접근의 한계를 드러내는 비교 기준*으로 위치시키는 것이 정직하다.

### 5.3 Jacobian Frobenius Anchor — 함수적 민감도(국소 기하) 정합

**Loss 정의**

feature를 입력에 대한 함수 $f(x)\in\mathbb{R}^d$로 보고, male 샘플 $x_i$에서의 **입력–출력 Jacobian** $J_i=\dfrac{\partial f}{\partial x}\Big|_{x_i}\in\mathbb{R}^{d\times|x|}$ 의 Frobenius norm을 anchor에 사용한다.

- **(B) 매칭형(주 형태, anchor에 충실)** — perturb-male의 민감도를 clean-male에 맞춤:
$$\mathcal{L}_{\text{Jac}}^{\text{match}}=\frac1N\sum_{i=1}^{N}\bigl\lVert J_i^{\,p}-J_i^{\,c}\bigr\rVert_F^2$$
- **(A) 정칙화형(경량·non-KD)** — male feature가 입력(=섭동)에 둔감해지도록:
$$\mathcal{L}_{\text{Jac}}^{\text{reg}}=\frac1N\sum_{i=1}^{N}\bigl\lVert J_i^{\,p}\bigr\rVert_F^2$$

**Frobenius 추정(필수)**: 전체 Jacobian($256\times3HW$)은 계산 불가 → **Hutchinson 무작위투영 추정**(Hoffman et al., 2019, *Robust Learning with Jacobian Regularization*)을 사용:
$$\lVert J\rVert_F^2 \;\approx\; \frac{d}{M}\sum_{m=1}^{M}\bigl\lVert \nabla_{x}\,(v_m^{\top} f)\bigr\rVert_2^2,\qquad v_m\sim \text{Unit sphere}(\mathbb{R}^d)$$
즉 출력공간 무작위벡터 $v_m$으로 $v_m^\top f$의 입력 그래디언트 노름을 평균.

**내 Task에서의 역할**

Centroid/CORAL이 feature의 *값·분포(어디·어떻게 퍼짐)*를 잡는다면, Jacobian anchor는 **"male 입력 주변에서 검출기가 입력 변화에 *어떻게 반응*하는가(국소 기하)"를 보존**한다. 우리 프레임워크 자체가 *입력 섭동*으로 동작하므로, "섭동이 male의 함수적 반응 표면을 왜곡하지 않게" 직접 제약하는 것은 **개념적으로 가장 자연스러운 anchor**다. 값이 조금 움직여도 *반응 구조*가 유지되면 male 검출 동작은 보존된다.

**선정 이유 / 적용 근거**

- **소표본 제약(C1) 우회**: centroid/CORAL/MMD는 "여러 male 샘플로 통계량(평균·공분산·분포)을 추정"하지만, Jacobian은 **샘플 1개마다 독립적으로 그 자체의 Jacobian을 제공** → $N=2{\sim}3$에서도 각 샘플이 완전한 제약을 줌. **rank 붕괴(C1·C2)에서 자유로운 유일한 후보.** (CORAL의 약점을 정확히 보완.)
- **섭동 프레임워크와의 정합**: 적대적 robustness 문헌의 Jacobian 정칙화를 그대로 차용 → "왜 이 loss인가"의 근거가 강함.
- **사다리 최상단**: 값→분포→함수로 가는 보존 사다리의 최심층. "분포 정합으로 부족하고 함수적 안정성까지 필요한가"를 검증.

**다른 loss 대비 장단점**

- 장점:
  - **유일하게 함수적/구조적 정보를 정합** — 값(L2/centroid)·분포(CORAL/MMD)와 **직교하는 증거** → 결과가 일치하면 신뢰도↑, 다르면 새로운 정보.
  - **소표본 강건(C1)**: 통계 추정이 아니라 per-sample 미분 → rank 무관(CORAL 대비 결정적 강점).
  - 섭동 안정성과 직결되어 male 검출 보존과 인과적으로 가까움.
- 단점:
  - **이중 역전파(2nd-order)**: Jacobian-노름의 gradient를 구하려면 그래프를 두 번 미분 → **메모리·시간 비용 큼**(가장 무거운 후보).
  - **BF16 수치 불안정(C3)**: 2차 미분은 mixed precision에서 불안정 → fp32 부분 사용/스케일링 필요.
  - **Hutchinson 추정 분산**: 투영수 $M$ 적으면 noisy, 키우면 비용↑.
  - **(B) 매칭형의 KD 인접성**: clean Jacobian을 "교사 신호"로 맞추는 형태는 *Jacobian matching*(Srinivas & Fleuret, 2018)로 **KD 변형으로 분류**됨 → 교수님 지적(KD 제외)과 충돌. **회피책: (A) 정칙화형**($\lVert J^p\rVert_F$ 최소화)은 교사 없이 self-stability만 거므로 **non-KD**로 안전하게 보고 가능. → **보고 시 (A)형을 기본으로 제시** 권장.
- vs **Centroid/CORAL**: 비용은 가장 크지만 잡는 정보가 질적으로 다름(함수 vs 값/분포). "값·분포를 다 맞춰도 함수적 반응이 무너지는가?"라는 질문에 답하는 유일한 후보.

### 5.4 3종 한눈 비교 (장단점 매트릭스)

| 기준 | ① Centroid | ② CORAL | ③ Jacobian Frobenius |
|---|---|---|---|
| 보존 대상 | 평균(위치) | 공분산(모양) | 입력–출력 민감도(함수) |
| 정합 차수 | 1차 | 2차 | 미분(구조) |
| 소표본 C1 (N≈2~3) | ◎ 평균 안정 | ✕ rank≤4≪256 | ◎ per-sample 미분(rank 무관) |
| 고차원 C2 (d=256) | ◎ | ✕ 공분산 256² | ○ (투영로 완화) |
| BF16 C3 | ◎ mean·내적뿐 | ○ Frobenius(안정) | △ 2차미분 불안정 |
| fairness shift C4 | ◎ 평균만 고정 | ○ 모양만 | ◎ 값 자유, 반응만 고정 |
| 계산 비용 | 매우 낮음 $O(Nd)$ | 중 $O(d^2)$ | **높음**(이중 역전파) |
| KD 여부 | non-KD | non-KD | (A)정칙화=non-KD / (B)매칭=KD인접 |
| 핵심 약점 | 분산·collapse 못 봄 | 소표본 rank 붕괴 | 비용·BF16·KD인접 |
| 본 task 위치 | **최소 정합 하한·핵심 직격** | **2차 단독의 한계 대조군** | **함수적 정합 상한·직교 증거** |

### 5.5 왜 이 3종 조합인가 (보고 논리 요약)

1. **차수 사다리 구성**: 1차(centroid) → 2차(CORAL) → 미분/구조(Jacobian)로, *male 보존에 어느 수준의 제약이 실제로 필요한가*를 단조적으로 분리한다.
2. **소표본 제약을 양 끝에서 검증**: centroid·Jacobian은 C1에 강하고, CORAL은 C1에 약하다 → 같은 실험 세트 안에서 **"소표본에서 2차 통계 추정이 왜 무너지는가"를 정량적으로 시연**(교수님 보고의 핵심 메시지).
3. **직교 증거**: 값(centroid)·분포(CORAL)·함수(Jacobian)는 서로 다른 정보를 잡으므로, **세 결론이 수렴하면 male 보존 결론의 신뢰도가 높아지고, 갈리면 어느 수준의 제약이 결정적인지** 알 수 있다.
4. **정직성**: CORAL·Jacobian의 한계(rank, 비용·BF16·KD인접)를 숨기지 않고 명시 → "그럼에도 보고/실험하는 이유(대조군·직교증거)"가 분명.

### 5.6 실험 매트릭스 (교란변수 통제, 본 3종 기준)

**고정**: contrastive(λ_con=5.0, τ=0.05), batch=5, epsilon 스케줄, β 스케줄, 동일 seed/epoch. **변경**: anchor loss만 교체.

| # | 앵커 | 검증 가설 |
|---|---|---|
| **E0** | L2 (baseline) | 절대좌표 고정 기준선 (no_l2 대비 male 보존 정도) |
| **E1** | **Centroid** | 평균 드리프트 차단(1차)만으로 male이 보존되는가 |
| **E2** | **CORAL (+Centroid)** | 2차(공분산)까지 잡으면 1차보다 나은가 / 소표본서 실제로 동작하는가 |
| **E3** | **Jacobian Frobenius (A형)** | 함수적 민감도 보존이 값·분포 정합보다 male 검출을 더 지키는가 |

**병행 진단지표**: male AP 보존(↑)·AP Gap(↓), male centroid drift $\lVert\mu^p-\mu^c\rVert$, male 분산/유효차원(collapse 감지), contrastive·det loss 곡선(안정성).
